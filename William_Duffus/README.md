# 《汕头白话英华对照词典》音韵词汇研究 —— 第八、九章数字化

## 项目简介

本项目对岳婕博士学位论文《〈汕头白话英华对照词典〉音韵词汇研究》（福建师范大学）的核心语料章节进行全流程数字化：该书底本为 1883 年传教士**威廉·达弗斯（William Duffus， 卓威廉）**编纂的汕头话（潮汕方言）英华词典，论文第八章「语汇集说明」与第九章「语汇集正文」（24 个语义分类小节，202 页）是其词汇研究的精华所在。

最终产出：逐页图片、25 个小节 Markdown、粗版/完整版合并文本（21 万字）、字音配对汇总表与校对报告，可直接用于方言词典检索、变调规则研究与 RAG 语料建设。

来源：《汕头白话英华对照词典》音韵词汇研究_岳婕（福建师范大学博士学位论文，CAJ 格式）
CAJ 经 caj2pdf 转为 PDF 后按页渲染为 PNG（200 dpi）。
